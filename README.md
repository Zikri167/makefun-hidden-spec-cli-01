mend is one command-line tool that applies the edits AI models write — unified diffs with wrong line numbers, SEARCH/REPLACE blocks, V4A patches and JSON tool calls — to a tree of text files, exactly as SPEC.md in this repository specifies. It finds the lines each edit names at the first of three matching tiers (exact, trailing-whitespace, whitespace-trimmed), and changes every file or none. Node 22, standard library only, deterministic and offline.

## Run it

```sh
node main.ts [options] [PATCH]
```
